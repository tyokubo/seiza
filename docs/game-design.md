# 星座ゲーム 企画・仕様書

状態：v0.1 / 2026-09-23。これまでの会話で確定した方針と、MVP向けの仮仕様を区別する。

## 1. コア体験

見えない星空を、通常観測と望遠鏡を切り替えながらダウジングの反応で探索する。見つけた星を使い、シンプルな外形と任意の顔スタンプからオリジナル星座を作る。星空は月替わりで、完成した星座は図鑑に残る。

プレイの中心：**探す → 発見する → 星をつなぐ → 名前・顔で仕上げる → 図鑑に残す**。

## 2. 決定済み仕様

### 通常観測モード

- 大まかな探索と方向決めのためのモード。探索対象の星は表示しない。
- ダウジング表示は出さない。
- 現在向いている範囲に星がどの程度多いかを、背景の明るさ・色・もや・模様の濃さで定性的に伝える。数値の密度表示はしない。
- 背景は真っ暗にせず、天球らしい雲・星雲・淡い模様を表示する。探索対象ではない極小の背景星は、移動感と天球らしさのために表示してよい。
- 水平線より上は夜空、下は黒い山や地面のシルエットとして表現する。地平線は画面固定ではなく、視点の上下移動に応じて動く。
- 探索対象の星は天球の上半球（地平線以上）だけに配置し、下半球の星は表示・密度・ダウジング・発見の対象にしない。
- 登録済みの星は通常モードにも表示する。探索円の密度判定は未登録の星だけを対象にする。
- Blender等で作成した2:1のEquirectangular全天球画像がある場合は、通常の2D背景として伸ばさず、球面の内側から透視投影で眺める背景として使う。
- 画面中央に透明な探索円を表示する。探索円は画面幅の75〜80%程度とし、円内の未登録星数に応じて縁と円の上側に置く密度アイコンを同じ色に変える。アイコンは円内や画面下部中央には置かず、実数も表示しない。
- 密度アイコンは、多い=オレンジ星3個、中程度=黄色星2個、少ない=水色星1個、反応なし=グレーのアイコンとする。多い判定はMVPでは探索円内4個以上とし、星を疎な領域と限られた密集領域に配置して、反応なしに偏らず、かつ多い表示が頻発しないようにする。閾値は設定ファイルから調整できるようにする。
- 通常モードの密度装飾は画面端を強く、探索円の周囲に向けて透明になるグラデーションとする。円内とその直近は透明なマスクで保護し、星なしでは消す。少ない=水色、中程度=黄色、多い=オレンジをアイコン・円周・装飾で共有する。色は即時に切り替え、光量だけ現在値から約140msで変える。色・光量・広がり・フェード速度は設定値で管理する。
- N/NE/E等の方位はゲーム内の地平線付近へ投影し、山の遠景に沿って移動・傾斜させる。起動時の基準方位をNとするゲーム内表示であり、地磁気による実方位ではない。
- スワイプによって視点を比較的大きく動かせる。
- 通常モードではジャイロによる視点操作も試作する。ジャイロが使えない環境や許可されない環境ではスワイプで代替できるようにする。
- ジャイロ再調整ボタンを用意する。押下時はスワイプで加わった視点差を取り除き、現在の端末姿勢が示す視点へカメラを滑らかに移動する。
- ジャイロの震えや急な動きは表示の平滑化と追従量の上限で軽減する。ただし目標の向きは失わず、動きを止めると端末姿勢に対応する向きへ追いつく。速い動きや遅い動きによってアプリ側の角度誤差を蓄積させない。
- ジャイロ操作はスマートフォンを縦に持つ前提とする。左右の向き変えは水平回転、上下の傾けは垂直回転として扱う。画面中心軸まわりの回転では視線方向を保ち、星空の画面内回転だけを反映する。

### 望遠鏡モード

- 通常モードの探索円内には、同じ視線で望遠鏡に切り替えた際の観測範囲を示す小円を表示する。円径は透視投影の視野角比から計算する。
- 未登録星は従来の色・明るさ・発光を維持し、タップ直後だけ短い白い波紋を表示する。登録済み星は星本体の色を変えず、望遠鏡モードでのみ小さな静止したオレンジリングとチェックマークで区別する。通常モードでは登録星本体だけ見せる。

- 狭い範囲を精密に探索するためのモード。
- 狭い視野内の星が見える。
- 望遠鏡では星本体・発光・登録表示を通常の2倍の大きさにし、タップ半径を32pxへ広げる。星空座標・発見条件・ダウジングは変更しない。
- 倍率を高め、星の間隔を少し広げて、一度に複数の星が見えすぎないようにする。試作値は通常視野角74度に対して望遠鏡のズーム係数4.6、星座標の間隔倍率1.2とする。
- モード切替ボタンは両モードで中央下部の同じ位置に置く。丸ボタン内は白い望遠鏡/戻る矢印だけとし、説明は下に置く。2本指を広げると望遠鏡、狭めると通常へ切り替える。閾値を超えたときだけ切り替え、短い円形ズーム演出と円/照準のフェード表示を行う。望遠鏡に入るときは視点中心を維持し、端末姿勢が有効なら通常へ戻るときはその時点の端末方向へ戻す。
- ダウジング表示は望遠鏡モードでのみ出す。
- ダウジングの反応文字は視野の上側に置き、方向矢印は円周の外側に沿って置く。最も近い未登録星の方向を指し、反応が強いほど明るく大きく脈動する。反応なしなら矢印は出さない。発見後は下部のモードボタン位置を一時的に登録ボタンへ切り替える。
- 通常モードと同じスワイプ量でも視点移動量が小さい（低感度）。
- **移動可能範囲に制限はない。** 何度でもスワイプできる。遠距離移動したいときに通常モードへ戻すと効率的。
- ジャイロが使えない場合、モード切り替え前後で視点方向を引き継ぐ。ジャイロ使用時は望遠鏡中のスワイプを通常モードの補正値に加えず、戻る際に現在の端末方向へ視線を合わせる。
- 星の方向・近さの手掛かりを、色・振動・矢印等のアニメーションで定性的に伝える（ダウジング）。数値の距離表示は不要。
- 見た目は「望遠鏡を覗いている」印象を優先し、円形視野、周囲の暗いマスク、中央照準を使う。
- 中央照準は実際の星と紛らわしくならないよう、中央に隙間のある短い十字線にする。中央の白い点や画面全体へ伸びる長い座標線は表示しない。
- 望遠鏡視野は四角い抜けに見えないよう、円形の覗き窓として背景をクリップ表示する。
- 視野内の未登録星をタップすると、視点が約420msで星を中央に捉え、「発見！」と登録ボタンを表示する。この間はレーダーを隠す。登録すると通常モードにもその星が見え、密度とダウジングの探索候補から除外する。登録状態は星空ごとに端末へ保存し、再起動後も復元する。
- レーダーが「反応なし」のときは方向矢印を表示しない。

### 星座制作

- 左下は星座図鑑、右下は「星座を作る」の入口とする。紺色の円が角から少しせり出し、アイコンとタップ領域はSafe Area内に置く。右下は探索円内に未使用の登録星が2個以上、または既存星座の使用星があるときだけ有効・拡大にする。250ms/400msの安定化と短いバネを維持する。望遠鏡中は制作不可。Home/Exploreタブは使わない。
- 開始前の選択画面で新規作成または既存星座を選ぶ。既存星座は本来の位置に表示し、名前の選択領域をタップできる。複数候補は一覧からも指定できる。選択後は1回につき1作品だけを編集し、他作品は25%の明るさで固定参照する。
- 1つの星は同じ月の星空内で1つの星座にのみ所属する。新規制作は未使用星だけ、編集は未使用星と自分の星だけ接続可能。別作品の使用星は操作・保存の両方で禁止する。所属は明示保存時に確定し、作品削除で再利用可能になる。過去月の所属は今月を妨げない。旧データで共有済みの星は作品を勝手に削除せず、制約違反の保存を拒否する。
- 制作へ入るときは探索のカメラ方向を引き継ぐ。制作中は登録済み星を同じ全天球投影で表示し、空白ドラッグで視点移動、ピンチで連続ズームできる。制作中のジャイロによる表示追従は止め、探索へ戻ると再開する。
- 星からドラッグすると指先への仮線を描く。別の星の34px以内で離すと吸着・確定し、空白ならキャンセルする。同じ星同士の逆順接続や自己接続は作らない。接続順序は自由で分岐も許可する。
- 確定線は細く表示し、線から14px以内のタップで削除する。移動した場合は視点移動として扱い削除しない。星の判定を線より優先し、星自体は削除しない。Undoは線追加・削除の両方を戻す。
- 2本指操作へ移ったら仮線を取り消し、全指を離すまで線操作を再開しない。接続は星IDの組で保存し、仮線とUndo履歴は保存対象外。登録状態は自動保存するが、制作中の接続・絵・顔・名前は自動保存しない。
- 制作は一画面に統合する。下部で接続・ペン・消しゴム・視点移動・顔を選ぶ。右上の完成ボタンの下に独立した56pxのUndo/Redoを並べ、目・虫眼鏡は下部に維持する。名前は40文字までで空白のみは不可。タイトルで変更する作業名は、完成まで保存しない。
- 外形は白〜淡い青白色のフリーハンド。描画可能範囲は接続線の丸端の帯と閉じた輪郭の内部の和集合。凹みを保持し、外接矩形や凸包で代用しない。帯半径は以前の0.045から0.09へ2倍にする（面積を一律2倍にする意味ではない）。`constellationEditor.bandRadius` で調整する。
- 描画は画面座標で速度に応じた軽い平滑化を行ってから星空座標へ変換する。小さな揺れは抑え、大きな移動は速く追従する。終点は入力位置へ追いつかせる。補正設定は `brushSmoothing` に集約する。消しゴムは削除予定のストロークを指の移動中から非表示にし、指を離すと確定する。
- 自己交差する接続成分では内部の塗りを生成せず、帯だけを有効にする。単純な閉多角形、分岐・開いた線を扱う。
- 範囲外から描き始めても、入った部分のみ表示・保存する。途中のはみ出しは分割し、戻れば続けて描ける。接続を削除すると再計算し、範囲外のストロークを切り取り、収まらない顔を除く。Undoで接続と絵をまとめて復元する。
- ガイド（接続線・半透明の領域）は表示切替可能で完成作品に含めない。接続線自体は独立データとして完成後の空にも細く表示する。
- 描画中の1本指は線、2本指の平行移動は視点移動、ピンチはズーム。途中で2本指になったら未確定線を捨て、全指を離すまで再描画しない。制作中はジャイロに追従しない。顔ツールで顔上から始めた2本指操作は顔の移動・拡縮・回転に固定し、背景を動かさない。顔以外ならキャンバスへ適用する。
- `assets/images/nikoniko.png` の透過画像をそのまま複数の顔として配置できる。下部の顔素材をドラッグ、または顔ツールを選んで領域内の空き位置をタップすると追加する。既存の顔をタッチするとその顔を選択し、ドラッグ・拡縮・削除できる。未選択の顔には影響しない。領域外は配置せず、狭い帯では初期サイズを縮める。顔なしでも完成できる。
- 手描き線は白色の細かな濃淡と輪郭の揺れを持つ。接平面の一定間隔とストロークIDから同じ模様を生成し、線の外へ粒子を散らさない。入力中・保存後・図鑑でも同じタッチを維持する。接続線は透明度40%で控えめに表示する。
- 編集では保存済みの内容を作業用データへ読み込む。明示的な完成・保存で同じIDを更新し、名前も星空の作品下に表示する。保存失敗時は画面に残り、作業と元作品を保持して再試行できる。
- 戻る矢印は「変更が保存されませんがよろしいですか？」と確認する。「制作に戻る」は内容を保持、「保存せずに戻る」は今回の作業・名前・仮所属を破棄する。新作は残さず、編集は最後の明示保存状態を保つ。作業とUndo/Redoはメモリのみで、再起動時も復元しない。
- 見た目の方向性：素朴でゆるい手描き感。特定ブランド・既存キャラクターの図案は複製しない。

### 月替わりと図鑑

- 毎月、星空**全体の配置**を更新する。星座だけの個別30日寿命、星ごとの個別30日寿命は採用しない。
- その月の星空に浮かぶ星座は、月替わりで現行の空から消える。
- 完成した星座は図鑑でいつでも見返せる。
- 図鑑の一覧・詳細から完成星座を削除できる。確認ダイアログでキャンセル可能。確定すると空・図鑑・保存データから対象作品だけを削除し、星の登録と他の作品は残す。確定後の削除は取り消せない。
- 現実装は端末のローカル暦月（仮仕様）で完成星座の表示対象を切り替える。完成作品は通常/望遠鏡の共通カメラに投影し、望遠鏡では円内だけ表示する。図鑑では保存した星座を選び、移動・拡大して見返せる。
- 星空の星配置そのものは従来の試作配置を維持する。月ごとの新しい星配置生成は別途実装する。
- 月ごとの星空全体のアーカイブは、実装可能性を見て追加する。現時点で必須ではない。

## 3. 初期MVPの仮方針（調整可能）

- まず2D仮想星空で、スワイプ・モード切り替え・方向決め・反応・発見だけ実装する。
- ジャイロ、振動、演出、クラウド同期を最初の完成条件にしない。ダウジングはまず画面上の色とアニメーションで試作する。
- 視野角・スワイプ感度比・ダウジング閾値は実機プレイで調整する。具体的な値は確定していない。
- 1日3分の探索時間はこれまでの企画上の方向性。**リセット時刻・中断中の計測・残り時間の扱いは未確定**。まずオン/オフ可能なゲーム設定として置く。
- 星の発見は望遠鏡視野内でのタップを条件とし、登録はボタン操作で確定する。
- 通常モードでは探索対象の星を隠したまま、背景の濃淡で星が多い方向を示す。濃淡の強さや表現方法はデザイン検証で調整する。
- 通常モードの密度判定はMVPでは探索円内の未登録星数を使う。未登録星そのものは通常モードで描画しない。
- `assets/images/sky-panorama.png` と透過付き `assets/images/mountain_new.png` は全天球テクスチャとして扱い、通常/望遠鏡モード共通のカメラ向きで表示する。描画順は空、望遠鏡モードの星、手前の山。山画像の素材姿勢と経度合わせは設定値で調整し、地面中心を世界の下方向に配置する。別の黒半球は重ねず、山画像の透過境界をそのまま山と空の境界にする。UI（探索円、密度アイコン、望遠鏡マスク/照準、ダウジング）はその上に重ねる。
- 探索画面のヘッダーは探索円に被らないようコンパクトに保ち、発見数などの補助情報は小さなチップとして表示する。

## 4. プレイ体験の設計意図

- 通常モード：大きく移動でき、星が多そうな方向を背景の濃淡で探せるが、個別の星やダウジング反応は見えない。
- 望遠鏡モード：星・探索反応という精密な情報が得られるが、1回の入力では大きく移動しづらい。
- プレイヤーが「このまま細かく探すか、一度望遠鏡を外して大きく動くか」を選べることが狙い。
- 顕微鏡における低倍率での広域探索／高倍率での精密観察が発想の参考。ただし物理的な挙動の厳密再現ではない。
- 星座制作では絵の上手さを求めず、星の形をどう見立てるかに集中できることを優先する。

## 5. 未決定事項（勝手に確定しない）

- 月末時点の未完成星座をどう扱うか。
- 星の配置が全ユーザー共通か、ユーザーごとに異なるか。
- 星空の世界座標の最終モデル（2D平面／球面、左右のラップ等）。
- ダウジングがどの星を対象にするか（最寄り／選択対象／複数の合成）。
- 月替わり基準のタイムゾーン、任意リセットの扱い。
- 図鑑の編集・再編集範囲、星空全体のアーカイブ方式。
- SNS共有、マネタイズ、対人機能。

未決定事項は、MVPを妨げる場合のみ仮仕様として実装し、設定や関数を分離して差し替え可能にする。
