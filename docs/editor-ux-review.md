# 星座制作 UI/UXレビュー

2026-09-26。コードと390x844のブラウザ画面で確認。iPhone実機の操作評価は未実施。

## 残る改善点

1. **対応済み: 保存完了を待ってから戻る。** 明示保存中は操作を停止し、保存に成功してから確定データと所属を更新して探索へ戻る。失敗した場合は制作画面で作業を維持し、再試行できる。
2. **P2: 接続線の削除が絵にも影響する。** `ConstellationDraft.tsx` の `lineDispatch` は変更後の領域で絵を即座にクリップする。通知とUndoはあるが、Undo履歴は再起動で消える。絵がある状態の接続削除には、影響範囲のプレビューや確認を追加する余地がある。今回は既存の接続削除操作を維持する。
3. **P3: 制作中の全体表示ボタンがない。** 制作画面を移動・拡大して星座を見失うと手で戻す必要がある。図鑑の `fittedCamera` 相当の「全体を表示」を制作側へ用意すると復帰しやすい。顔は素材ドラッグまたは領域内タップで追加する。

## 今回の対応

- 1セッション1作品、開始時の新規/編集選択、他作品の薄い参照と星の所属制約を追加。
- 制作中の自動保存を廃止し、戻る確認から実際に変更を破棄できるように変更。
- Undo/Redoは右上の独立56pxボタンへ移動。描画中も2本指で移動・ズームし、顔上では顔の回転・拡縮を優先。
- 手描き線を再現可能な濃淡・輪郭の揺れへ変更し、保存後も同じ質感を維持。

- 段階タブを撤去し、接続・描画・消しゴム・視点移動・顔素材を1画面に集約。完成は右上に常設。
- 主要ツールに短い名称を付け、選択状態を明示。視点ズームと顔のサイズ変更を別のコントロールへ分離。
- 顔を素材からドラッグ追加。実画像のプレビュー、有効/無効の枠、配置後の選択枠、移動・拡縮・削除を追加。無効な場所で離した場合は元の状態を維持。
- 接続線周辺の描画帯半径を2倍。描画入力に速度依存の平滑化を適用し、終点は離した位置まで反映。
- 消しゴムの削除予定を指の移動中から表示に反映。中断した場合は確定しない。
- 図鑑の一覧・詳細から確認付きで星座を削除。登録星と他作品を維持。

## 実機確認項目

- 顔素材を指で持ち出して、範囲内/範囲外へ離す。配置後の顔の移動と拡縮。
- 小さな曲線・ゆっくりした線・速い線で、平滑化の遅れが気にならないか。
- Safe Area込みで下部ツールが押しやすいか。指による絵の遮蔽と消しゴムの反応。
