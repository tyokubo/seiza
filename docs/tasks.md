# 実装タスク・受け入れ条件

記号：`[ ]` 未着手、`[x]` 完了。進捗はCodexで実装した都度更新すること。

## フェーズ0：環境と設計

- [ ] Expo公式テンプレートが起動する。
- [ ] 既存のAGENTS.mdを保持し、ゲーム固有の指示を統合する。
- [ ] docsの仕様を読み、未決定事項を不用意に実装しない。
- [ ] Gitの初期コミットを作成する（ユーザーのリポジトリへのpushは明示指示後）。

**完了条件**：Expo画面が起動し、型チェックが通る。既存設定が不必要に壊れていない。

## フェーズ1：星空探索の最小プロトタイプ【最優先】

- [ ] 2D世界座標に複数の星を配置する（まず固定配置でもよい）。
- [ ] カメラ状態と、スワイプ入力による移動を実装する。
- [ ] 通常モードでは星を非表示にする。
- [ ] 望遠鏡モードは狭い視野内の星だけ表示する。
- [ ] 望遠鏡モードは1回のスワイプによる移動量を小さくする。
- [ ] **望遠鏡モードでも何回でも移動可能**。モード切替後も視点位置を維持する。
- [ ] 最寄りの候補星について、方向と近さを計算する（対象選定はMVPの仮仕様）。
- [ ] 数値の距離表示に頼らないダウジングUIを試作する。
- [ ] 視野内の星の発見を表示する（仮の獲得条件を明記）。
- [ ] カメラ・方向/距離・発見判定の単体テストを追加する。

**完了条件**：通常モードで大移動→望遠鏡で反応を追い→星を見つけられる。望遠鏡に移動限界が存在しない。Android/iOSの少なくとも手元の実機で操作感を確認する（実機未確認なら未検証と明記）。

## フェーズ2：探索の手触り調整

- [ ] 感度、視野、反応閾値を設定ファイルへ集約する。
- [ ] 見失いにくさ・難易度・モード切替頻度を実機で調整する。
- [ ] ジャイロ操作は必要性を確認して追加する。
- [ ] 振動・音・発見演出は効果を見て追加する。
- [ ] 1日3分の仕様詳細を決めてから時間制限を実装する。

**完了条件**：星を探す行為そのものが成立し、設定値を変更してテストできる。

## フェーズ3：星座制作

- [ ] 発見した星の一覧・配置を編集画面へ渡す。
- [ ] 星を順番に選び、外形の線を作れる。
- [ ] やり直し/一手戻すができる。
- [ ] 任意の顔スタンプ（目と口のセット）を最後に配置できる。
- [ ] 顔スタンプなしで完成できる。
- [ ] 名前を付け、構造化データで保存できる。

**完了条件**：絵を手描きせずとも、星をつないで星座を完成できる。

## フェーズ4：図鑑・月替わり

- [ ] ローカル保存を導入する。
- [ ] 完成星座を図鑑から開いて再描画できる。
- [ ] 現在の月の星空を選択/生成する。
- [ ] 月替わりで現行の星空を切り替える。
- [ ] 過去の完成星座が月替わり後も残ることをテストする。
- [ ] 月別星空全体の保存は、負荷・容量を見て追加するか判断する。

**完了条件**：アプリ再起動・月更新でも完成した星座が失われない。

## フェーズ5：必要になったら追加

- [ ] Supabase Auth・同期・RLS
- [ ] SNS用の画像出力・共有
- [ ] 音・振動・アニメーションの調整
- [ ] アーカイブの閲覧と月別振り返り
- [ ] 運用・クラッシュ報告・公開準備

## AIへの実装指示ルール

- フェーズ単位、または小さな完了条件単位で実装する。全フェーズ一括実装は依頼しない。
- 変更後に型チェック・テストを実行し、結果と未検証事項を報告する。
- 仕様が未決定なら仮実装の意図と差し替え箇所を明記する。
- 既存Expo設定や保存データを破壊する変更は、必要性を説明する。
