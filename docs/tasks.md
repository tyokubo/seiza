## フェーズ1：星空探索の最小プロトタイプ【最優先】

- [x] 2D世界座標に複数の星を配置する（まず固定配置でもよい）。
- [x] カメラ状態と、スワイプ入力による移動を実装する。
- [x] 通常モードでは星を非表示にする。
- [x] 望遠鏡モードは狭い視野内の星だけ表示する。
- [x] 望遠鏡モードは1回のスワイプによる移動量を小さくする。
- [x] **望遠鏡モードでも何回でも移動可能**。モード切替後も視点位置を維持する。
- [x] 最寄りの候補星について、方向と近さを計算する（対象選定はMVPの仮仕様）。
- [x] 数値の距離表示に頼らないダウジングUIを試作する。
- [x] 視野内の星の発見を表示する（仮の獲得条件を明記）。
- [x] カメラ・方向/距離・発見判定の単体テストを追加する。

Phase 1の仮仕様：固定星空を使用し、ダウジング対象は未登録星のうち最寄りの星とする。星を望遠鏡視野内でタップすると中央へ寄り、発見表示の後に登録ボタンで確定する。視野に入っただけで自動発見しない。

Phase 1仕様修正：通常モードは大まかな方向決め用とし、探索対象の星とダウジングは表示しない。星の多そうな方向は背景の濃淡・もや・探索対象ではない極小背景星で示す。望遠鏡モードは円形視野・暗いマスク・中央照準を持つ精密探索用とし、星とダウジングは望遠鏡モードでのみ表示する。スワイプと端末姿勢を切り替えやすい入力変換層を用意する。

UI修正：通常モードは、動く地平線と山/地面シルエットを持つ夜空背景、画面幅75〜80%程度の透明な探索円、探索円内の未発見星数に応じた密度アイコンを表示する。望遠鏡モードは中央点と画面全体の座標線を削除し、円形視野、暗い外周マスク、中央に隙間のある短い十字線を表示する。密度閾値は設定ファイルで調整する。

全天球背景修正：`assets/images/sky-panorama.png` を2D背景として伸ばさず、`expo-gl` でEquirectangularテクスチャとしてサンプリングする。背景、星描画、密度・発見・ダウジング判定は同じ単位クォータニオンカメラと球面方向を使用する。

山レイヤー修正：透過付き `assets/images/mountain_new.png` を同じ全天球投影へ追加し、空→星→山の順で描画する。山画像の地面中心はテクスチャ座標の+Z方向にあるため、`gameConfig.panorama.mountainRotationDegrees` のX軸+90度で世界の下方向（-Y）へ配置する。サンプリングにはその逆回転を使用し、DBGの山UVにも同じ変換を適用する。向きのずれを隠していた黒半球の補完処理は撤去し、地面は山画像の不透明部分だけで描画する。経度合わせは `gameConfig.panorama.mountainLongitudeOffsetTurns` で調整可能。経度折り返しの継ぎ目を避けるため、山テクスチャにはミップマップを適用しない。空画像の回転と端末姿勢の計算は変更しない。

探索調整：ジャイロ再調整ボタンはスワイプ分のずれを除いたジャイロ基準姿勢へカメラを滑らかに戻す。探索対象星は上半球に限定し、少数の密集領域を含めて星の出現頻度を上げる一方、「多い」（星3個）判定の閾値は4個を維持して頻発を避ける。

開発診断：開発ビルドでのみデバッグ表示を開ける。視線ベクトル、方位/仰角、空と山の中央UV、スワイプ量と視線ベクトル差分、ジャイロ状態を確認できる。DeviceMotionの姿勢角・回転速度・画面向き・要求/観測更新間隔と、姿勢角から作った生/平滑化クォータニオン、ゲーム内カメラ姿勢を併記する。iOSの観測更新間隔はネイティブ値の秒をミリ秒へ直して表示する。山と空の境界をタップしてその画面座標・視線方向・UVを記録し、カメラを動かしてもマーカーは同じ世界方向を指す。スクリーンショットで共有できる。

UI/操作修正：ヘッダーと補助表示をコンパクト化し、探索円への重なりを避ける。望遠鏡モードの四角い抜けをやめ、円形にクリップした全天球背景を覗き窓として表示する。通常モードでは `expo-sensors` のDeviceMotionを使い、縦持ち時の3軸姿勢から基準姿勢に対する目標カメラ姿勢を求める。使えない環境ではスワイプ操作にフォールバックする。

ジャイロ累積ずれ修正：小さな回転の無視と大きな回転の切り捨てによる積算誤差を解消する。平滑化と1更新の表示回転量上限は維持し、未反映の回転量は次回以降に追従する。スワイプ分は端末姿勢と別管理し、再調整ではスワイプ分だけを滑らかに除く。望遠鏡モードでは表示を端末に追従させず、追跡基準はモードをまたいで保持する。速度の異なる往復、複数軸回転、微小な継続移動、震え軽減、ドラッグ中の端末移動、再調整の中断、モード切り替えをドメインテストで検証する。iPhone実機での追従感とセンサー由来のずれは別途確認が必要。

探索の微調整：望遠鏡ズーム係数を2.3へ上げ、試作星座標の間隔を1.2倍、通常探索円を画面幅の80%へ広げる。密度アイコンは望遠鏡レーダーと同じ画面上の基準位置へ揃える。レーダーが無反応のときは矢印を隠す。望遠鏡内の未登録星をタップすると視点が中央へアニメーションし、発見表示・登録ボタンへ切り替わる。登録済みの星は通常モードにも描画し、未登録星だけを密度とダウジングの候補とする。試作段階の登録状態はメモリ上で保持する。

**完了条件**：通常モードで大移動→望遠鏡で反応を追い→星を見つけられる。望遠鏡に移動限界が存在しない。Android/iOSの少なくとも手元の実機で操作感を確認する（実機未確認なら未検証と明記）。

## フェーズ2：探索の手触り調整

- [x] 起動時のピッチ・ロールを水平として扱わず、重力基準と方位基準を分離する。斜めでの起動後の水平復帰・机上回転を数値テストする（実機確認は別途必要）。
- [x] 通常モードに望遠鏡視野の内円を追加する。
- [x] 登録済み星のレーダー除外、静止オレンジリング、未登録星のタップ直後の白い波紋を追加する。
- [x] 望遠鏡倍率を4.6にし、登録リング・チェックは望遠鏡内だけに表示する。右下の固定ボタン、2本指でのモード切替、誤操作防止閾値、短いズーム演出を追加する。
- [x] 密度アイコンを探索円の上へ移し、外縁も密度の色に合わせる。矢印レーダーと登録操作を視野外の左上へ移し、切替ボタンを中央下部へ配置する。
- [x] レーダーを視野円周と統合し、反応文字を円上へ移動する。切替ボタンを白い単色アイコンの丸形にして位置を上げ、発見時は同じ位置で登録できるようにする。登録済みのチェックを正しい向きへ直し、円/照準の登場をフェードさせる。
- [x] 望遠鏡から通常へ戻る際、ジャイロがあれば最新の端末姿勢へ復帰し、ジャイロがなければ望遠鏡の視点を保持する。望遠鏡のスワイプは通常の補正値へ混ぜない。
- [x] 通常モードの探索円外に密度色の減衰光を追加し、星なしでは消灯する。UIレイヤーで色と強さを連続補間し、設定値で調整できるようにする。
- [x] 左下を図鑑、右下を制作入口に分離する。未使用星2個以上または編集候補があるときだけ制作可能状態にする。

- [ ] 感度、視野、反応閾値を設定ファイルへ集約する。
- [ ] 見失いにくさ・難易度・モード切替頻度を実機で調整する。
- [ ] ジャイロの軸方向、中心軸回転、揺れを実機で確認して調整する。
- [ ] 振動・音・発見演出は効果を見て追加する。
- [ ] 1日3分の仕様詳細を決めてから時間制限を実装する。

**完了条件**：星を探す行為そのものが成立し、設定値を変更してテストできる。

## フェーズ3：星座制作

- [x] 星からのドラッグ・吸着で自由な接続を作り、空白リリースでキャンセルする。重複・自己接続を防ぐ。
- [x] 細い線に広めの削除判定を設け、追加・削除をUndoできる。
- [x] 空白ドラッグによる視点移動、ピンチによる連続ズーム、2本指移行時の仮線取消を実装する。
- [x] 登録状態は自動保存し、制作データは明示保存時だけ所属検証を行って確定する。
- [x] 画像顔スタンプをタップまたはドラッグで複数配置し、選択した顔を移動・拡縮・削除できる。
- [x] 顔スタンプなしで完成できる。
- [x] 帯と凹多角形内部の描画領域、はみ出しクリップ、手描き・消しゴム・ガイドを実装する。
- [x] 線・絵・顔に共通のUndo/Redo、視点移動モード、ズームを実装する。
- [x] 制作を一画面に統合し、帯幅2倍、手ぶれ補正、消しゴムの即時プレビューを追加する。
- [x] 顔を素材パレットからドラッグ追加し、有効/無効の選択枠と専用操作を用意する。
- [x] 図鑑の完成作品を確認付きで削除できる。
- [x] 完成作品を再編集し、同じIDで置き換える。星空にも名前を小さく表示する。
- [x] 新規/編集の対象選択、1セッション1作品、他作品の薄い参照表示と所属制約を実装する。
- [x] 描画中の2本指移動・ピンチ、顔の2本指回転、右上の独立Undo/Redoを実装する。
- [x] 戻る確認で新規作業・既存編集を実際に破棄し、元作品と所属を維持する。
- [x] 再現可能な線の質感と望遠鏡の星サイズ拡大を実装する。

探索UI更新：左右の角に制作と図鑑を分離する。制作可否は未使用星・編集候補で判定する。密度装飾と方位・ジャイロは維持し、Home/Exploreタブは復活させない。

**完了条件**：絵を手描きせずとも、星をつないで星座を完成できる。

## AIへの実装指示ルール

- フェーズ単位、または小さな完了条件単位で実装する。全フェーズ一括実装は依頼しない。
- 変更後に型チェック・テストを実行し、結果と未検証事項を報告する。
- 仕様が未決定なら仮実装の意図と差し替え箇所を明記する。
- 既存Expo設定や保存データを破壊する変更は、必要性を説明する。
